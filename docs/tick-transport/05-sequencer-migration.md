# Этап 5. Миграция секвенсора на ticks

Статус: запланировано. Зависит от этапов 1–4.

## Задача

Убрать из `Sequencer` `_lastStepAt`, `_stepPeriodUs`, `sync(micros)` и
`update(micros)`. Секвенсор принимает transport-команды и на границе каждой
шестнадцатой планирует MIDI-события, но не отправляет их сам.

## Контракт

- Один владелец считает шесть ticks на шестнадцатую — transport/adapter, не
  `ExternalMidiClock` и не скрытая копия в `Sequencer`.
- При boundary: сначала поставить Note Off активной ноты с `(T, 0)`, затем Note On
  включённого шага с `(T, configuredPhase)`. Для zero swing обе ноты имеют фазу 0.
- Outgoing clock уже поставлен или отправлен раньше тех же событий: фактический
  порядок на `(T, 0)` — `F8`, Note Off, Note On.
- Stop и reset очищают будущие ноты и гарантируют один Note Off для активной ноты.
  Start начинает с step 0 ровно один раз.
- Редактирование шагов меняет будущие решения; не должно изменять уже отправленный
  пакет или вызывать запись в flash из transport-пути.

## Реализация

1. Сначала добавить новый API рядом со старым и перенести native-тесты
   `sequencer.cpp` на `advanceTick`/`advanceSixteenth`. Удалять time API только
   после переключения интеграции этапа 6.
2. Вынести состояние активной ноты из `main.cpp` в контроллер воспроизведения
   либо задокументировать его единственным владельцем. Нельзя оставить два пути,
   которые оба посылают Note Off.
3. Подключить очередь из этапа 2. При enqueue failure применить общую policy
   overflow, определённую на этапе 2.
4. Сохранить UI snapshot текущего шага: он обновляется от transport boundary,
   LVGL по-прежнему только читает `UiViewModel`.

## Проверки

Шаг 0 на Start, 6 ticks на шаг, 16 шагов на паттерн, enabled/disabled step,
velocity, Note Off перед следующим Note On, Stop, Continue, boundary паттерна,
редактирование во время работы и порядок `F8 → Off → On`.

## Вне объёма

Настройка swing пользователем и изменения UI, кроме сохранения существующего
отображения позиции.

## Передача результата

Заполнить фактический API, владельца ноты, удалённый time API и тесты.
