# Этап 7. Swing через фазовый offset и сквозная проверка

Статус: запланировано. Зависит от этапов 1–6.

## Задача

Использовать уже готовый процентный `phase` для swing. Swing не создаёт вторую
сетку времени, не сдвигает MIDI Clock и не меняет transport tick/позицию шага.

## Согласованный контракт

- Прямой режим: Note On каждого шага планируется с `phase = 0`.
- Swing сдвигает только нечётные шестнадцатые (индексы 1, 3, …) на положительную
  фазу их tick-интервала. Чётные остаются на границе.
- UI-параметр Swing и функция преобразования в phase должны иметь явно выбранный
  диапазон и кривую. До реализации зафиксировать: максимум не должен пересекать
  следующую границу tick; рекомендуемая верхняя граница — меньше 100% с запасом.
- Note Off предыдущего шага остаётся на границе нового шага (`phase = 0`), чтобы
  сдвинутая Note On не порождала непредсказуемое перекрытие. Альтернативный gate
  дизайн — отдельная будущая функция.
- При смене swing во время проигрывания новое значение влияет только на ещё не
  поставленные либо ещё не отправленные события, в соответствии с зафиксированной
  политикой очереди; уже отправленное не перепланируется.

## Реализация

1. Выделить чистую `SwingPhase` функцию и native-тесты до подключения энкодера.
   Она принимает шаг и пользовательское значение, возвращает phase; не получает
   BPM или время.
2. На boundary секвенсора использовать результат только для Note On. Убедиться,
   что `F8` и phase-0 Note Off продолжают уходить раньше.
3. Подключить существующий `swingCounter` через application state. При необходимости
   уточнить его диапазон и отображение, не создавая доступа к LVGL с main core.
4. Провести измерения, сравнивая 0%, 50% и 75% phase при нескольких BPM и внешнем
   master. Относительная доля должна сохраняться при смене темпа.

## Полная матрица приёмки

- `make verify` проходит; тесты включены в `test/test_native/main.cpp`.
- Внутренние 24 PPQN стабильны, а 16th ровно на каждом шестом tick.
- В `Internal` на общей границе порядок `F8 → Note Off → Note On`; в `Off` clock
  отсутствует, но ноты сохраняют фазу; в `External` outgoing `F8` отсутствует.
- Offset 50% и 75% сохраняет долю интервала на 40/120/240 BPM и при live BPM change.
- Внешний master с изменяемым и умеренно jittery tempo не даёт двойных шагов,
  пропущенных Note Off или зависших нот; loss безопасно останавливает transport.
- Swing 0 воспроизводит прямой ритм; swing не сдвигает `0xF8`, чётные шаги и
  транспортную позицию.
- На железе подтвердить результат MIDI monitor/DAW и, если доступно, логическим
  анализатором/временными отметками USB host.

## Вне объёма

Ratchet, независимый gate-length, humanize, per-step microtiming, DIN MIDI и
Song Position Pointer. Они могут переиспользовать `(tick, phase)` позже, но не
добавляются этой задачей.

## Передача результата

Указать кривую swing, выбранную верхнюю фазу, результаты измерений и отклонения.
