# Этап 2 — LittleFS и ячейки программ

Статус: планируется.

## Цель

Добавить устойчивое хранилище для 16 пользовательских ячеек и скрытой Current
Program, не привязывая доменную модель к Arduino API.

## Работа

1. Настроить и смонтировать LittleFS без неявного форматирования при ошибке.
2. Определить адресацию ячеек `0`–`15` и `Current Program` (`16`).
3. Для каждой логической ячейки использовать две физические копии A/B.
4. При сохранении записывать следующую ревизию в неактивную копию, проверять
   записанное содержимое и только затем считать её актуальной.
5. При загрузке выбирать новую валидную копию по CRC и ревизии; если обе
   невалидны, сообщать, что ячейка пуста или повреждена.
6. Изолировать LittleFS в Arduino-адаптере; native-тесты должны использовать
   in-memory fake storage.

## Проверка

- сохранение и загрузка всех 17 логических ячеек;
- перезапись не меняет другие ячейки;
- незавершённая новая копия не уничтожает предыдущую;
- выбор новой и fallback к старой валидной копии;
- ошибки mount/read/write не приводят к форматированию или потере данных.
