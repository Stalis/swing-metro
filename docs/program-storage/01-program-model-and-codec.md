# Этап 1 — модель Program и расширяемый codec

Статус: планируется.

## Цель

Создать независимую от LittleFS модель сохраняемой программы и её двоичный формат.
Она должна представлять все текущие пользовательские параметры и безопасно
расширяться без потери возможности читать сохранения старых прошивок.

## Работа

1. Ввести `Program` и `ProgramStep`: global-поля, 16 шагов и преобразования
   между Program, counter'ами, sequencer и MIDI Clock settings.
2. Определить defaults для всех полей, включая будущие step-поля, отсутствующие
   в старых программах.
3. Реализовать заголовок контейнера: magic, версия, ревизия, размер и CRC.
4. Реализовать bounded TLV-codec без heap: отдельные теги для global settings,
   данных шагов и будущих расширений.
5. Reader обязан игнорировать неизвестные теги, подставлять defaults для
   отсутствующих и отвергать некорректные длины, CRC и версии контейнера.

## Проверка

- round-trip актуальной программы;
- старый payload без будущего поля загружается с default этого поля;
- неизвестный тег не ломает известные данные;
- повреждённые длина, CRC и magic отклоняются;
- размер кодируемой программы имеет фиксированную верхнюю границу.
