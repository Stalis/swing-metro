# Этап 3 — модальное управление Save / Load

Статус: планируется.

## Цель

Дать безопасный пользовательский сценарий выбора Save или Load и одной из 16
ячеек через ручку Volume.

## Работа

1. Добавить long-press Volume, не меняя короткое нажатие Shift.
2. При срабатывании long-press немедленно отправлять Note Off, останавливать
   sequencer и переводить координатор в Program Storage context.
3. В первом экране энкодер Volume выбирает `Save` или `Load`; его нажатие
   открывает список ячеек `0`–`15`.
4. Во втором экране энкодер выбирает ячейку, нажатие запускает операцию.
5. Пока контекст активен, поглощать локальные Start/Stop и блокировать применение
   External MIDI Clock Start/Continue. На выходе reset external clock state;
   транспорт остаётся остановленным.
6. Публиковать в UI состояния выбора, занятости, успешного завершения и ошибки.

## Проверка

- короткое Volume по-прежнему работает как Shift;
- long-press останавливает транспорт и гасит ноту до открытия UI;
- действия и ввод вне модалки не протекают в главный контекст;
- Save/Load используют выбранные тип действия и ячейку;
- после закрытия transport остановлен, а External Start нужен заново.
