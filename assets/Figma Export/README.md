# Figma Export — реестр интерфейса

Экспорт страницы **Silkscreen Flat study** для реализации секвенсора на LVGL.
Этот файл фиксирует размеры, координаты и состояния, чтобы не обращаться к Figma
для базовой разметки. Векторные SVG — источник геометрии; PNG — только превью.

Фигма использует логический холст **160×128 px**. В текущем firmware графический
буфер PicoDisplay объявлен как 128×160, поэтому перед пиксельной проверкой нужно
подтвердить ориентацию и преобразование координат.

## Основной экран 160×128

- Фон: `#000000`.
- Верхняя строка: `124 BPM`, `CLK`, режимы `OFF / INT / EXT`.
- Разделитель: `x=3, y=11, w=154, h=1`, цвет `#585C58`.
- Статус секвенции: `SEQ 01 | MIDI CH / ALL` слева, `SWING 62%` справа.
- Сетка: 4×4 карточки, размер каждой **36×23 px**, шаг по X **39 px**,
  шаг по Y **26 px**; левый верхний угол первой карточки `x=3.5, y=24.5`.
- Карточки содержат номер, ноту (или `OFF`), `VEL` и `GATE`.
- Нижний ряд может быть отключённым и показывает `--`.
- Активный шаг меняет цвет рамки; отдельная дополнительная рамка не добавляется.

## Модальные состояния

Каждый пример — копия экрана 160×128. Общая подложка: чёрный шахматный дизеринг
1 px с покрытием 50%. Панель: **148×112 px**, чёрная, рамка 1 px `#58F8F0`.

| Пример в SVG | Содержимое |
|---|---|
| `Step settings / Normal` | `STEP 01`; активны `MODE`, `NOTE`, `VEL`, `GATE`; `REPEAT COUNT` серый |
| `Step settings / Legato` | Активны `MODE` и `GATE`; остальные строки видимы, но серые |
| `Step settings / Repeat` | Активны все строки, включая `REPEAT COUNT` |
| `MIDI Clock / Select` | `OFF`, `INTERNAL`, `EXTERNAL`, `CANCEL`; отдельно показан текущий режим и фокус |
| `Sequence storage / Actions` | Меню `SAVE`, `LOAD`, `CANCEL`, `RESET` |
| `Sequence storage / Save slots 01–05` | Список слотов, 6 видимых строк, индикатор прокрутки, начало списка |
| `Sequence storage / Load slots 06–11` | Та же модалка, середина списка |
| `Sequence storage / Save slots 11–16` | Та же модалка, конец списка |
| `Main screen / Reset confirmation` | `RESET SEQ?`, `CURRENT ONLY`, `NO / YES`, по умолчанию `NO` |

Переиспользуемые заготовки находятся в том же SVG: `Modal / Dither backdrop` и
`Modal / Panel base`. `RESET` относится к текущей секвенции и не изменяет сохранённый слот.

## Компоненты

`Sequencer Components.svg` содержит варианты карточки шага: обычная, выбранная,
отключённая и с активным шагом, а также пары «лейбл + параметр». Лейбл и значение
разнесены по ширине строки; `VEL` и `GATE` используют Cyan. Для LVGL сохранять
фиксированные размеры, 1 px рамки и выравнивание параметров по правому краю.

## Правила использования

1. Для реализации брать координаты и цвета из SVG; не измерять PNG вручную.
2. `@2x` и `@4x` не являются отдельными макетами.
3. Значения в SVG — примеры для сравнения кадров. Прошивка показывает реальные tempo,
   swing, шаги и позицию транспорта. `Mode` и `Repeat Count` пока только визуальные поля:
   текущий режим всегда Normal до реализации Legato/Repeat.
4. При изменении макета повторно экспортировать SVG/PNG и обновить этот реестр.
